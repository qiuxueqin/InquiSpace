# 简洁界面改版说明

日期：2026-11-04。范围：阶段一单角色沉浸式探究交互原型。

本次改版让师生直接看到教学内容、学习结果和下一步行动。发布校验自动执行；运行轨迹和 JSON 不进入师生页面。原始对话、来源、内部记录与历史成果继续保留。

## 界面变化

| 场景 | 现在如何操作 |
| --- | --- |
| 教师设计 | 写一句教学需求，点击“生成教学方案”；资料和详细配置收在“更多设置”。 |
| 确认方案 | 看“和谁对话、探究什么、课堂安排”三块内容；需要时展开“和角色试聊”。 |
| 发布 | 系统自动校验，缺少内容时只提示补充项；选择学生并确认教学内容后发布。教师无需点检查或阅读测试报告。 |
| 学生探究 | 直接提问、追问和表达判断。回答状态只显示“正在准备回答”“正在回答”等日常用语。 |
| 学生报告 | 默认展示自动小结、探究过程条形图和下一步建议；“查看对话依据”按需展开。 |
| 教师报告 | 先看课堂小结和建议，再看参与人数、完成进度、探究行为图表及学生学习情况。 |
| 查看详情 | 点击图表回查相关原话；点击学生报告查看小结、图表、建议及学生补充。完整对话默认折叠。 |
| 教学备注 | 按需展开，使用“引用资料是否可靠”“学生是否有进一步思考”等教学语言。 |
| 导出 | 导出当前任务、所选发布范围的 HTML 图文教学报告；不导出整个工作区的 JSON。 |

教师页面已移除可见的“AI 发布前检查”、检查卡片、重新检查按钮、技术修订号和运行步骤配置。学习报告已移除运行轨迹及 JSON 展示，内部记录没有删除。

资料来源仍可查看原文；图表基于实际演示操作记录，不提供能力分数或学习成绩。报告只整理学生已经表达的内容，角色观点另列，不能代写学生尚未形成的结论。

## 保留的发布规则

- 生成方案、打开预览和确认发布时自动执行相应检查；修改后旧结果失效，发布时按最新内容重新校验。
- 缺失历史时间、不可用资料、资料范围错误等仍会阻止发布。具体缺失信息去重，不再叠加通用检查失败提示。
- 教师仍需选择发布学生，并确认教学内容适合本次课堂。
- 已发布方案有明确只读提示，通过“修改方案”进入新版流程；历史学习记录不被覆盖。

当前是纯前端原型，“自动校验”指不需要师生操作的内部逻辑，并非已经部署真实后端。正式实现必须在服务端执行权限、资料状态、内容版本和发布事务校验，不能信任浏览器状态。

## 本轮验证

使用 `?review=qa` 隔离工作区，通过真实页面控件交互，没有向浏览器注入业务状态。

| 验证项 | 结果 |
| --- | --- |
| 自动发布检查 | 新建工业革命主题，未填年代时不能确认发布；补充 1850 后直接发布成功，无需手动重新检查。 |
| 缺失提示 | 定向脚本核对缺失年代只出现一条清楚提示；补充后自动检查通过，已有失败标记仍能阻断。 |
| 学生学习闭环 | 实际发送两轮表达、选择一次“需要更多证据”，结束后直接得到学习报告，没有成果表必填项。 |
| 报告更正 | 学生追加“只是提出一种可能”的补充后，教师报告同步显示，原话继续保留。 |
| 图表回查 | 点击“反思修正”条形图可读到相关学生表达，并保留回到对话入口。 |
| 历史报告 | 切换“历次发布”后，原任务的 3 份学习记录仍在；旧已提交成果可展开阅读。 |
| 技术内容移除 | 学生报告和教师详情未出现运行轨迹、运行事件或 JSON；页面中没有原日志用的 `pre` 元素。 |
| 图文导出 | 实际点击下载；检查文件含课堂小结、进度图及学生报告，不含脚本、运行日志、业务交互属性或其他任务内容。 |
| 响应式 | 桌面 1440×1000 与手机 390×844 检查报告和发布页；手机页面宽度与内容宽度一致，没有整页横向溢出。学生表格保留自身横向滚动。 |
| 代码与状态 | 47 项现有状态规则测试通过；本轮追加检查脚本语法、提示去重、发布阻断、静态 ID 唯一、六页面结构与构建一致性。已操作页面的浏览器错误日志为空。 |

导出文件完成下载与内容结构检查；内置浏览器限制直接打开本地 `file:` 页面，因此未声称完成导出 HTML 的独立浏览器视觉验证。在线原型的报告布局已经实际查看。

## 演示边界与后续衔接

原型尚未接入真实 AI。方案、回答和总结由本地规则与模板演示，顶部及“使用帮助”保留简短说明。正式版应由 AI 根据对话与资料生成可读小结，图表数值仍由可核对的学习事件计算，并保留原话定位及学生更正。

接口和数据库设计需沿用内部 Trace / Evals 记录，面向师生的报告接口返回摘要、图表统计、教学建议和原话依据，不返回原始运行日志。本轮未改写既定需求、接口或数据库文档。

本次测试只新增 QA 任务及其学习记录，没有清空普通工作区、已有任务或历史对话。改版前完整副本：`../../work/prototype-simple-before-LilP42/opendesign-prototype/`。
