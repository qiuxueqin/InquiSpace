# AI 协作改版说明

日期：2026-11-03。范围：阶段一单角色交互原型。

后续更新：2026-11-04 已进一步简化师生界面。本文保留历史改版记录；可见预检摘要、运行轨迹等约定已被 [简洁界面改版说明](./简洁界面改版说明.md) 替代，以当前页面及 README 为准。

本轮依据用户新要求调整操作方式：减少教师备课配置，取消学生重复填写成果，把思考留在探究对话中，让 AI 整理已有过程，并让教师通过图表了解全貌、回查证据。

## 操作变化

| 使用场景 | 改版后 |
| --- | --- |
| 教师创建任务 | 主界面只需一句教学需求，学科和年级提供默认值，参考资料可选；完整配置默认收起。 |
| AI 准备任务 | 补齐角色、情境、目标、问题链、边界和报告形式。保留原资料，提供撤销本次改写。 |
| 教师审核发布 | 查看三张关键方案卡及一次完成的五类预检摘要，按需试问，选择学生并作一次明确发布确认。 |
| 信息不完整 | 历史时间不明时要求补充，不偷偷生成年代；改动角色、时间或资料会使旧检查失效。 |
| 学生探究 | 直接提问、追问、核对来源、提出判断与反思。回答旁的三种判断选择是可选辅助，理由仍在聊天中表达。 |
| 学生学习报告 | 自动提取探究起点、学生已表达的判断、求证、反思和疑问；可回到对应原话。无需重新填写成果表。 |
| 学生结束 | 有一次学生表达且无运行中的回答即可结束并保存报告；不以结论、反思或笔记填写作为门槛。 |
| 学生更正 | 可选追加一句补充或更正；原话和原记录不覆盖，教师端同步可见。 |
| 教师报告 | 指标卡、进度环形图、行为条形图、学生×行为矩阵；图例可筛选，计数可回查。人工评阅默认收起。 |

## 报告可信度与统计口径

- 学生观点只来自学生消息；角色回答单独展示，不将角色的“我认为”归给学生。
- 原型按关键词识别求证、个人判断和反思，所以呈现为“表达线索”，不声称完成语义或能力评估。
- 摘要引用学生原话概括起点、最近明确判断和未解决疑问；没有相关表达时不补写结论或虚构观点变化。
- 表达次数包含学生实际发送的消息；失败/停止仍保留表达，只有完成的回答才计入完整轮数。
- 查看来源按会话内不同文件去重，必须是该学生已展示引用的来源；不将教师点击和旧版未采集行为补入统计。
- 判断表达为明确观点消息与对具体角色回答的判断选择之和。改选同一回答不重复计数；各类别允许重叠。
- 参与人数按学生去重，会话与结束报告按会话计数；不同版本可切换或汇总，分母不混用。
- 未记录不等于没有思考，点击次数不等于理解或成绩。报告不提供虚构雷达分数或能力排名。

## 实际交互验证

使用本机浏览器 `?review=qa` 隔离工作区，经页面控件进行操作，未通过脚本注入业务状态。

| 场景 | 已观察结果 |
| --- | --- |
| 一句话设计 | 从新建任务选择“身份与权力”，生成完整方案、五类演示预检通过。 |
| 发布门槛 | 未勾选关键内容确认时发布按钮禁用；选择陈、李两位学生并确认后发布成功。 |
| 学生自然表达 | 陈同学实际完成三轮提问、判断和反思，无任何成果表必填项。 |
| 判断辅助 | 选择“需要更多证据”后显示求证提示；“说说理由”只预填输入框，不自动发送。 |
| 运行跨页 | 回答生成中查看报告，结束按钮禁用；回答完成后状态自动更新。 |
| 自动报告与更正 | 结束后三轮记录形成报告；学生补充保留，教师可以查看。 |
| 图表一致性 | 测试任务有两位学生、两个会话、三轮完整对话、一份已结束报告。表达 3、求证表达 2、来源查看 0、判断表达 3、反思表达 2，与实际记录一致。 |
| 图表回查 | 点击判断条形图及学生反思格子，显示原话；继续点击可定位完整对话。进度图例筛选生效。 |
| 空记录与隔离 | 李同学新会话为零表达，不混入陈同学报告；空会话结束操作提示先进行一次探究。 |
| 历史兼容 | 旧任务全部版本仍显示三个历史会话，旧已提交成果在报告中只读保留。 |
| 缺少历史时间 | 新历史主题未给年代时预检阻断；只补充 1850 后重新检查通过。 |
| 修改与撤销 | 修改时间立即清除旧预检；撤销 AI 改写恢复原草稿。 |
| 非历史主题 | “湿地生态”方案无需历史时间，通过预检；自由试问可用。 |
| 响应式 | 桌面 1440×1000、手机 390×844 检查设计页、报告及回查。页面无横向溢出；手机弹窗宽 364px，内部无额外横向滚动。行为矩阵允许在自身容器内横向滚动。 |

自动检查：47 项状态规则测试通过；包括来源点击授权/去重、判断改选、原话归属、预检失效、历史快照及无成果表结束等。脚本语法、静态 ID 唯一、六页面、新交互结构、无长成果表、高级设置默认折叠、构建一致及无远程运行依赖核对通过。最终浏览器错误日志为空，覆盖本轮已操作路径。旧 `submit` 保留用于历史兼容，新界面不调用长表单提交流程。

本轮来源事件的详细授权/去重边界由状态测试覆盖；新发布演示任务为零资料，没有声称完成新资料的真实检索验收。

## 设计文档衔接

此次用户要求替代旧设计中两项交互约定：教师五次逐项人工确认、学生三个成果必填字段。保留单角色、资料来源、认知边界、教师发布确认、版本冻结及历史可追溯约束。

原需求、技术方案、接口和表设计文件未直接重写。正式开发前需要同步以下契约，不能照旧成果提交接口直接接入：

1. 任务方案生成与预检：教学意图输入、结构化方案、假设/缺失信息、关联修订号、结果状态、撤销草稿。
2. 学习事件：来源打开、针对回答的判断选择；记录学生、会话、版本、消息或来源 ID、时间；服务端鉴权、去重与幂等。
3. 自动学习报告：运行中更新与结束后报告、引用消息 ID、原话与归纳分离、缺失项、生成状态与版本；真实模型生成失败可重试，原始对话不能丢失。
4. 报告更正：追加学生说明，保留原报告及更正历史，不能覆盖原话。
5. 教师聚合：按任务/版本/授权范围聚合，统一人数与会话分母，支持图表钻取到来源、原话和运行轨迹。

## 原型边界与文件

AI 生成、对话、预检、摘要和教学观察仍由本地规则与模板模拟，尚未接入真实模型。鉴权、持久化服务、PDF 解析和语义检索也未实现。新 TXT 可本地读取但不自动参与语义回答，新 PDF 会明确标为解析失败并阻止发布。图表使用实际浏览器演示记录，不使用占位成绩。
