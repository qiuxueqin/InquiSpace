## 结论

原原型的视觉方向符合阶段一，但部分交互和状态规则不符合当前实施设计，不能直接作为开发验收基线。本轮已在浏览器实际操作后修改原型，并复验教师设计、预览发布、学生探究、来源与笔记、成果、报告及历史版本等主要流程。

修订后的交互可用于阶段一原型评审。真实模型、资料解析、检索、鉴权、数据库及服务端事务仍需按技术方案实现，本记录不表示阶段一产品已经验收。

## 不符合项与修复

| 发现的问题 | 修订后的行为 | 对应设计 |
| --- | --- | --- |
| 未发布时也能直接开始学生演示 | 学生任务列表只显示已发布、当前授权的任务；必须进入本人会话 | M01、M05 |
| “创建任务”未形成独立任务 | 每次创建独立草稿，原任务和学生数据保留 | M02 |
| 发布新版本可能替换旧会话、笔记和成果 | 发布内容冻结；显式创建新草稿；每学生每版本独立会话，历史入口可恢复 | M02、M06 |
| 时间与角色候选联动不足 | 时间变更使核验失效；候选按当前角色、时间、目标生成，确认应用后刷新边界与问题链 | M04 |
| 资料范围与不可用资料的发布约束不足 | 角色资料范围可选择；未就绪/失败资料阻止发布；零资料允许，但不可伪造引用 | M03、M05 |
| 外部知识范围缺少具体说明入口 | 允许背景知识时必须填写具体范围；首版不自动联网 | M03 |
| 预览、角色核验与发布确认关联不足 | 五类预览和字段检查绑定当前修订；修改内容后失效；发布需人工勾选确认 | M04、M05 |
| 学生身份与路由混用 | 显式选择教师/学生账号；页面跳转不自动冒充另一身份；陈、李各自维护会话 | M01 |
| 停止仅展示结果状态，缺乏已输出部分 | 分块输出；停止保留已展示片段并标记不完整；失败和取消不计轮数 | M06 |
| 重试和运行限制容易改变已有快照 | 重试新建 Run、复用原用户问题；异常选择只影响下一轮，不改发布快照 | M06 |
| 截止、结束会话及轮次门槛不完整 | 轮次与截止在发送时检查；结束需确认；结束后可整理未提交成果 | M06、M07 |
| 所有成果字段都被当作必填 | 按接口只要求结论、角色观点、反思；其他项目可选；证据可直接从本人已展示引用选择 | M07、接口 Submission |
| 提交后文案及笔记操作不一致 | 提交后对话、笔记与成果冻结，提示明确；尚未提交的已结束会话仍可整理 | M07 |
| 生成期间进入成果页，完成后按钮未同步 | 回答完成后同步刷新成果页，解除运行期间的提交禁用 | M06、M07 |
| 教师报告缺少完整版本、证据和具体对象 | 按历史会话汇总；可回看学生所选证据、笔记判断和可信程度；风险定位到回答与运行轨迹 | M08 |
| 报告刷新可能回到先前任务 | 保存当前选中任务，刷新继续显示该任务报告 | M08 |
| 归档后缺少恢复入口 | 保留数据，任务列表支持恢复；归档期间学生不可访问 | M02 |
| 角色视角、资料范围等文案写死 | 绑定当前草稿或会话快照；自由预览在任务/修订变更后清空旧结果 | M02、M04 |
| 正文偏小、对比度不足，手机操作入口缺失 | 提高主要正文和操作字号与对比度；手机单列对话和笔记；保留账号入口 | 原型可用性 |

这些身份、版本与权限约束在本原型中属于本地交互规则，不提供服务端安全保证。

| 人工确认 | 五类通过后，不勾选确认仍不可发布；勾选后发布 v1 | 通过 |

| 时间与候选 | 时间改为 1913-01-01 出现角色时间冲突；改为“虚拟报童”，候选展示对应姓名与时间，确认后应用 | 通过 |
