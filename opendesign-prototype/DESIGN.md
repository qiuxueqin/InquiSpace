# 知境 · 设计交接

## 目标与范围

阶段一单角色沉浸式探究：教师描述教学意图并确认 AI 方案，学生在对话中核验资料、表达判断，AI 整理已有学习过程，教师通过图表回看。

不加入多角色切换、圆桌或独立治理平台。自动整理报告可以呈现学生已表达的结论，不替学生编造尚未表达的结论。

## 视觉规则

- 安静的教学工作台；低饱和绿色与纸白，赭色表示待确认或证据不足。
- 主色 #245a48；页面背景 #f7f8f4；边线 #e2e7dc。
- 系统无衬线字体；场景标题和人物名使用系统宋体回退。
- 主体圆角 14px，按钮 8px，标签 5px。
- 桌面导航 218px，内容最大宽 1440px；内容边距 38px，栅格间距 18～23px。
- 900px 以下折叠导航；620px 以下表单及多列内容改为单列。
- 图标为内置矢量，无在线字体、图片或脚本依赖。

优先通过 CSS 变量和公共组件修改，避免逐页产生不一致的样式。

## 必须保留的交互

- 修改时间、目标、资料或角色后，核验和预览结果失效。
- AI 方案可一键应用到草稿并撤销；发布、归档和结束探究需明确确认。
- 发布条件包含当前修订字段检查、五类预检及关键内容人工确认；取消五次人工逐项勾选。
- 检查自动执行，不显示技术检查卡片、运行状态、修订号或重新检查按钮；仅用日常语言说明需要补充的信息。正式版必须由服务端执行发布校验。
- 报告默认呈现小结、图表和下一步建议，原话、资料及完整对话按需展开。运行轨迹、JSON 和内部事件只作系统记录，不放进师生界面或教学报告导出。
- 草稿与会话快照独立，旧会话不自动更新。
- 新发布版本保留旧会话、笔记、引用与成果；同学生同版本重复进入恢复原会话。
- 新任务创建独立草稿；归档后保留历史，教师可恢复。
- 资料不足不创建引用，冲突材料并列展示。
- 来源包含文件与位置，抽屉保留上下文。
- 收藏和判断选择为可选；说理由仍在对话中进行，不增加独立必填表单。
- AI 报告区分学生原话、学生选择、角色观点与来源行为；缺失内容标为未表达，保留原话定位。
- 自动报告不替学生推断未表达的立场或观点变化。原型关键词归类必须注明演示边界。
- 结束后对话与摘录只读；学生可以追加报告更正，原话和旧成果继续保留。
- 图表基于实际事件。来源按会话内不同文件去重；打开来源不等于理解，行为次数不等于成绩。
- 历史会话缺少采集事件时不补造点击；教师查看来源不计入学生行为。
- 风险记录定位具体回答；成功拦截不算角色违规。
- 输入内容作为文本显示，不作为脚本执行。

## 给 OpenDesign 的修改约束

> 在当前 index.html 上修改视觉设计，保留单角色阶段一范围及现有交互属性和元素 id。保持一句话生成、默认收起的“更多设置”、自动内部校验、人工发布确认、来源抽屉、对话判断、自动报告与图表回查可用。师生页面只呈现教学内容、结果和必要的补充提示，不恢复检查面板、运行轨迹、JSON 或长成果表，不编造学生结论。完成后在 Preview 检查完整交互。

## 给前端开发者的交接约束

> 以最终确认 HTML 为视觉母版，迁移到 React + TypeScript，复用相同视觉与响应式规则。按《AI协作改版说明》和《简洁界面改版说明》补齐学习事件、自动报告、更正及服务端发布校验契约。检查生成可撤销、修改后自动重新校验、发布确认、来源回查、失败重试与结束后只读状态。技术记录保留在内部，师生只看教学结果；浏览器状态和固定演示回答不代表真实后端或模型验收通过。

## 动态内容编辑

角色名、任务标题等会由脚本绑定值更新。OpenDesign 中直接修改可见文字可能被运行状态覆盖。

- 静态文案和样式可用可视化编辑。
- 默认业务数据在 Code 中编辑对应 data-model 表单默认值。
- 默认值只影响新建数据。已有任务通过页面编辑与新版本流程修改，不清空保存记录。
- `?review=qa` 使用独立检查数据，避免测试污染普通演示任务。正式原型数据使用 `zhijing-opendesign-v2`，旧版 `zhijing-opendesign-v1` 存储保留，不展示其原始 JSON。
- 导出后将导出 HTML 作为新的母版，不用旧 src 覆盖。
